## Evidence and decision vocabulary

- **Verified text:** an official repository page, license, manifest, or metadata file read at the exact revision below on **2026-10-15 UTC**. Repository metadata fields are recorded as written, without treating `author`, `date`, or `creation_date` as proof of the actual collector or capture time.
- **Catalog-listed artifact:** a named file or directory was listed at that revision. No archive, EVTX, or Git LFS log body was acquired or inspected. Raw event availability, parseability, internal timestamps, sensitive content, hashes, and completeness remain unverified.
- **Planned:** a possible EGIS-SOC homelab collection task; no run, alert, event, artifact, or annotation exists by virtue of this plan.
- **Rights review required:** repository-wide license text is evidence about the repository, not proof that every bundled log, payload, third-party work, or generated event has the same rights. A public URL does not authorize public republication of raw telemetry.
- **Use:** `E1/E2 pilot` means development/diagnostic suitability only. `E3 candidate` means a possible independent B source after W1-07 audit and W7 gates. None is confirmatory-ready.

For every acquired artifact, W2 must record the exact source URL and revision; acquisition UTC time/method and custodian; source-provided checksum if any; local raw-store key and SHA-256 over persisted bytes; decoded time zone; original event/run/template/collection lineage; source event ID; incident and tenant IDs; and transformations. The existing [EvidenceProvenance](../../src/egis_soc/schemas.py) and [EvidenceEvent](../../src/egis_soc/schemas.py) contracts provide snapshot fields; W1-07 must store lineage outside the current W1-03 models. An incident [bundle](../../src/egis_soc/schemas.py) needs a justified evidence boundary and scope check. Evaluation [gold](../../src/egis_soc/schemas.py) remains separate. A valid ID or digest does not prove event truth or claim support.

## Cross-source blockers and disposition

1. **Rights:** OTRF's MIT/GPL conflict, unverified artifact-specific ownership for every public source, Atomic dependencies, and private homelab telemetry prevent a blanket raw-data redistribution decision. Record a rights reviewer and disposition per chosen artifact before W2 acquisition/public release.
2. **Provenance:** Public metadata does not establish original event truth, actual collection operator, complete capture window or independent incident count. A repo, file, YAML ID, or ATT&CK technique is not an incident. W2 must record missing values as unknown, not manufacture them.
3. **Schema:** Source-specific parsers, UTC conversion, exact raw-store digest verification, event identity and incident/tenant scope are W2 work. Do not change W1-03 models to hide missing provenance; reject or quarantine an artifact that cannot meet the contract.
4. **Annotation:** W1-04 requires independent gold facts from permitted source evidence, S/C/I judgment against fixed evidence, separate citation relevance, and audit records. Metadata narratives and emulation ground truth can guide candidate screening but cannot be copied into gold as observed facts.
5. **Isolation:** OTRF APT29/APT3 and LSASS family relations require connected-component treatment; B1–B3 are only a preliminary B pool. W1-07 decides exact group keys, overlap, sealed access and freeze. No pilot score can be promoted into a confirmatory result.

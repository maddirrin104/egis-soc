## Selection rule and W2 entry gates

Prioritize a candidate only when a human can obtain lawful access to a coherent source-event window, identify the original run and collection lineage, preserve immutable raw bytes and provenance, map events to the [W1-03 schemas](../../src/egis_soc/schemas.py), and independently annotate critical facts from observable evidence under the [approved guideline](../annotation-guidelines.md). Prefer multiple relevant event sources, aligned timestamps, causal context, negative/uncertain evidence, and several independently checkable atomic claims. Apparent attack narrative, filename, ATT&CK tag, or dataset description alone is insufficient. A single repository, archive, or EVTX file is not automatically one incident. W1-07 must decide split groups and overlap **before** any held-out designation; W2 pilots remain development/diagnostic material. Source-derived pilot claims cannot replace the approved protocol's later frozen, arm-independent draft-derived RQ1/RQ3 claim pairs ([protocol v0.2](../research-protocol.md) §3).

The priority is a **screening order**, not a verified feasibility score. Every public row remains conditional on artifact rights, raw availability, parseability, time/boundary audit and privacy review. A rejected candidate is recorded as rejected; it is not silently replaced by a fabricated incident. `Catalog only` means the official metadata or directory was inspected at a pinned revision; **no raw events were downloaded or normalized**. `Planned/no capture` means a homelab task exists only on paper.

## W2 sequence and stop conditions

1. Resolve permission for internal use and artifact handling, then screen O2/O5 metadata and a narrowly selected raw artifact **only if authorized**. Keep O1 **RESERVED / METADATA-ONLY** until the owner and W1-07 decide its A/B role; no O1 raw events, descendants, annotations or generated artifacts may enter A development before that decision. Choosing O1 for A removes it as an available confirmatory B fallback. O3/O4 test additional LSASS variants but remain one suspected lineage group; O6/O7 are scope-sensitive reserves. Record rejected paths and reasons.
2. Inventory actual homelab sensors and safe capture authority, then implement only approved H tasks with a human operator. Treat all H tasks as development pilots from the same provisional environment family. Their future telemetry is not a separately operated Environment B.
3. For every accepted pilot, establish raw-store digest, source event IDs, time zone, transformation history, scope, candidate cluster/lineage, privacy classification, artifact rights and independently reviewed observable critical facts. Apply the [annotation guideline](../annotation-guidelines.md); missing evidence is `insufficient`, not `contradicted`.
4. If these checks do not yield 10–15 **actual** lawful, bounded, evidence-rich pilots, report the achieved number and shortfall. Do not count catalog entries, artifact files or runs as completed incidents. W1-07 owns final lineage grouping and held-out isolation, and W7 owns the conditional evaluation gates.
